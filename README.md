# BIC-MAC MICCAI 2026 Methodology

This public repository contains the methodology paper for Team `heyufan1995`
(`MIAgent`) in the BIC-MAC Challenge at MICCAI 2026.

- [Methodology PDF](BIC_MAC_MIAgent_Methodology.pdf)
- [Accessible Markdown source](bic_mac_methodology.md)

The final method uses a four-input residual 3D U-Net with direct supervision
in a narrow two-sided band around the real-CT body contour. It uses only the
provided BIC-MAC training data.
